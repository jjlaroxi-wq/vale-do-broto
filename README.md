# Vale do Broto

Protótipo de jogo 2D de fazenda e exploração, feito com HTML, CSS e JavaScript puro.

## Como jogar

Abra `index.html` em um navegador. Use WASD ou as setas para andar. Selecione ferramentas com as teclas 1 a 6 e pressione E ou clique no mundo para interagir.

O progresso é salvo automaticamente a cada cinco segundos e ao fechar ou sair da página. Também é possível salvar manualmente pelo botão de disquete. Os dados ficam no armazenamento local do navegador e são carregados automaticamente ao retornar no mesmo navegador.
